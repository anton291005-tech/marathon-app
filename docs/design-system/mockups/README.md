# Mockups

Referenz-Entwürfe der sechs Tabs (390 × 844 px, iPhone). Im Browser öffnen, über die Tab-Bar verlinkt.

- Die Zahlen sind Beispieldaten aus Woche 1. Echte Werte kommen aus der App.
- Maßgeblich sind Aufbau, Hierarchie, Abstände, Farben, Icons und Texte.
- Icons sind Lucide (inline SVG). In der App `lucide-react` verwenden, gleiche Namen.
